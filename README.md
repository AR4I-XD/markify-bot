# Markify Bot 🎨

Telegram-бот для автоматического брендирования фотографий: наложение логотипа в правый нижний угол с адаптивным масштабированием и опциональная автоцветокоррекция.

## Основные возможности

- 📐 **Идеальное позиционирование логотипа**: логотип всегда размещается в правом нижнем углу и масштабируется пропорционально размеру кадра (независимо от того, 4K это, вертикальное фото для Stories 9:16, горизонтальное 16:9 или квадрат 1:1).
- 🪄 **Автоцветокоррекция**: автоматическое улучшение контраста, баланса уровней и динамического диапазона (с возможностью отключения).
- 🛡️ **Конфиденциальность (Zero-Storage)**: бот обрабатывает изображения только в оперативной памяти (в потоках байтов) и не хранит фотографии пользователей на диске.
- 👤 **Пользовательские логотипы**: каждый пользователь может загрузить свой PNG-логотип с поддержкой прозрачности.
- ⚙️ **Гибкие настройки**: выбор масштаба логотипа, прозрачности и переключение автоцветокоррекции через удобное инлайн-меню.

## Установка и запуск

### 1. Клонирование и подготовка окружения

```bash
git clone https://github.com/your-username/markify-bot.git
cd markify-bot
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Конфигурация

Скопируйте `.env.example` в `.env` и укажите токен вашего бота от [@BotFather](https://t.me/BotFather):

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
BOT_TOKEN=ваш_токен_бота
```

### 3. Запуск

```bash
python -m src.main
```
